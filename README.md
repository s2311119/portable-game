# portable-game
```text
① 明らかなバグだけ直す
Skill初期化、ドロップ、item ID、経験値進化、最低ダメージなど。
以下
・Skill::dependence/category
・戦闘ドロップ処理
・ボス・特殊敵のアイテムID
・複数レベルアップ時の進化
・最低ダメージ/回復
② 進化システムを整理する
5系統をどう分岐させたいかを先に決めてからテーブルを書き直す。
③ ゲームバランスを数値で見る
各Lvの味方ステータス、敵ステータス、与ダメージ、必要戦闘回数などを表にして調整する。
④ 最後にリファクタリング
大量に残っている昔のコメントアウトコードを削除し、9,000行の .ino を少し整理する。
```

| 優先度 | 場所 | 現在見つかっている問題 |
|---|---|---|
| **最優先** | セーブ/ロード | **ロードすると保存したHP/TPが正しく復元されない可能性が高い** |
| **最優先** | スキル | 123/127のランダム多段攻撃が**二重ループ** |
| **高** | ボス/セーブ | bossFlagsは保存されるが、**ロード時にbossFlagsを読む前にマップを再生成**している |
| **高** | ボス | 50Fより先に進めてしまい、60Fで**bossFlags[5]範囲外**＋ボスID0になる |
| **高** | 敵AI | メンダー系AIが**存在しない回復スキルID 100/101を探している** |
| **高** | 戦闘 | `turnCount` が表示ターンより1進んでおり、ボスAIの3/4ターン周期がズレる |
| **中～高** | スキル | 攻撃＋状態異常技が**攻撃を外してもデバフだけ入る** |
| **中** | ターゲット | 挑発/かばう処理が `SINGLE_ALLY` にまで適用され得る |
| **中** | 反射 | 回復以外なら反射判定するため、**バフ・蘇生・治療・TP回復まで反射し得る** |
| **中** | スキル | 「かく乱」はコメントでは攻撃＋混乱だが、実装は**混乱だけ** |
| **中** | 回避バフ | `evaBuffRate` は設定されるが、**命中計算で使われていない** |
| **低～中** | 回復計算 | 最低1にしてから `/4` しているので、低値だと**0回復**になり得る |
| **保守性** | 全体 | `main.ino` にMap/Status/Skill/Battle/Save/Menu等が約9,000行集中 |
